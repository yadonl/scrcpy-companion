# 让 iPhone / iPad 用上这台安卓机（浏览器端）

桌面端靠 scrcpy 原生窗口；苹果这边不装 App 也能用，走的是**网页版投屏**：手机浏览器打开一个地址，画面和触摸都在网页里。

```
安卓机 ──adb──> 常开的机器（NAS / 小主机）──HTTPS+WebSocket──> iPhone Safari
```

## 需要什么

- 一台**常开**的机器（NAS、小主机、树莓派都行），Node.js 18+
- [ws-scrcpy](https://github.com/NetrisTV/ws-scrcpy)（网页版 scrcpy，WebCodecs 硬解）
- 安卓机开着「无线调试」，和这台机器在**同一个局域网**
- 一张证书（自签即可，见下）

## 装

按 ws-scrcpy 官方 README 安装（`npm install` → `npm run build` → 启动，默认端口 8000）。本项目不复制它的安装命令，避免版本漂移后误导你。

要点只有两条：

1. **必须能连到安卓机的 adb**：先 `adb connect 手机IP:端口`，网页端才会出现设备。
2. **必须加访问令牌**：网页端暴露在局域网里，任何能访问的人都能控制你的手机。ws-scrcpy 支持 token 校验，务必打开。

## HTTPS 是硬要求（不然 Safari 黑屏）

Safari 只在**安全上下文**（HTTPS 或 localhost）里开放 WebCodecs。用 HTTP 打开页面，通常表现为"设备列表有、画面一片黑"。

三种做法，任选：

| 做法 | 说明 |
|---|---|
| 反代 + 自签证书 | Caddy / Nginx 套一层 HTTPS，反代到 8000。iOS 首次访问要点「继续访问」 |
| 内网证书 | 有域名和内网 DNS 的话，用 ACME DNS-01 签一张真证书最省心 |
| Tailscale + `tailscale cert` | 装了 Tailscale 的话一条命令拿证书，iPhone 装 Tailscale 后直连 |

自签证书在 iOS 上还需要信任一次：**设置 → 通用 → 关于本机 → 证书信任设置**。

## 用

1. iPhone Safari 打开 `https://<你的地址>/`
2. 输入令牌，进控制台，选中那台安卓机
3. 点「视频」，画面出来；触摸即操作
4. 声音默认不播（iOS 需要你先点一下页面才能出声），需要就点音频按钮

## 踩过的坑

| 现象 | 原因 / 处理 |
|---|---|
| 页面能开，画面全黑 | 走的 HTTP。换 HTTPS，或先确认浏览器支持 WebCodecs |
| 设备列表空的 | 服务器上没 `adb connect`，或手机端没点「允许调试」 |
| 昨天能用今天连不上 | 无线调试端口变了。用 `adb tcpip 5555` 固定，或写个脚本重连 |
| 用一会儿断开 | Safari 切后台会挂起 WebSocket；回前台重连即可，别指望后台常连 |
| 局域网能开，4G 打不开 | 本来就该如此——这套设计前提就是"不出户"。要在外面用，走 Tailscale/WireGuard 回家，别把端口映射到公网 |
| 手机烫、耗电 | 网页端是持续编码，属正常。安卓机插电 + 通风，别捂在被子里 |

## 关于"隐私"

网页端这条路的隐私边界比云手机强得多：视频不过任何第三方服务器，令牌在你手里，断网即不可达。但请记住一条——

**谁能连上这台机器的 8000 端口，谁就能操作安卓机。** 所以：令牌必开、HTTPS 必上、路由上别做公网端口映射。
